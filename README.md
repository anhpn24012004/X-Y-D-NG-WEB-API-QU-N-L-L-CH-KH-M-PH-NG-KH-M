# XÂY DỰNG WEB API QUẢN LÝ LỊCH KHÁM PHÒNG KHÁM
Sinh viên xây dựng một ứng dụng ASP.NET Core Web API trên .NET 8 để quản lý thông tin phòng khám. Ứng dụng cần kết nối SQL Server bằng Entity Framework Core, sử dụng AutoMapper để ánh xạ Entity và DTO, đồng thời tổ chức code theo mô hình 4 tầng trong cùng một project.
